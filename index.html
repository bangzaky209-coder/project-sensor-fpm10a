Tentang Sistem

    
Sistem ini mendemonstrasikan keamanan pintu otomatis berbasis autentikasi sidik jari dengan mikrokontroler Arduino: pemindaian, verifikasi pengguna, pengendalian pengunci elektronik, dan monitoring status pintu.

    
    
      
  1. Sistem standby dengan pintu terkunci.
    2. 
      
  2. Pilih sidik jari terdaftar atau tidak terdaftar, lalu tekan Scan Fingerprint.
    3. 
      
  3. Sensor memindai, lalu sistem memverifikasi.
    4. 
      
  4. Jika valid: Access Granted, pengunci dilepas, pintu Unlocking lalu Open.
    5. 
      
  5. Setelah durasi terbuka berakhir, pintu Locking lalu Locked kembali (jika Auto Lock aktif).
    6. 
      
  6. Jika tidak valid: Access Denied dan pintu tetap terkunci.
    7. 
    

  









  

    
Simulasi Sistem Pintu Otomatis Berbasis Sensor Sidik Jari dan Arduino. Tujuan: mendemonstrasikan proses pemindaian, autentikasi, kendali pengunci, dan pencatatan aktivitas.

    
Teknologi: HTML, CSS, JavaScript, Arduino (disimulasikan), sensor fingerprint (disimulasikan), solenoid door lock (disimulasikan).

    
Secara bawaan sistem yang ditampilkan adalah simulasi berbasis browser: tidak membaca sidik jari asli dan tidak mengontrol pintu fisik. Mode Live bersifat opsional dan hanya memantau data serial dari Arduino.
